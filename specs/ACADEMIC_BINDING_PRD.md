# 教务绑定功能 PRD

## 1. 功能概述

用户通过绑定教务系统账号，获得完整平台权限。未绑定用户只能查看脱敏信息，无法进行敏感操作。

## 2. 用户故事

### 2.1 绑定教务
> 作为用户，我希望绑定我的教务账号，以便使用平台的完整功能。

**验收标准：**
- 用户可提交学号、教务密码进行绑定
- 系统验证教务账号有效性
- 绑定成功后显示真实姓名、学院等信息
- 绑定失败给出明确错误提示

### 2.2 查看绑定状态
> 作为用户，我希望查看我的绑定状态，以便了解账号权限。

**验收标准：**
- 显示是否已绑定
- 已绑定显示学号、姓名、学院、专业
- 提供解绑功能（需二次确认）

### 2.3 权限控制
> 作为平台，我希望控制未绑定用户的权限，保护敏感信息。

**验收标准：**
- 未绑定用户查看联系方式时显示脱敏（如：138****1234）
- 未绑定用户无法查看完整地址、真实姓名
- 敏感操作（发布、接单等）提示需要先绑定

## 3. 功能需求

### 3.1 教务绑定接口

| 接口 | 方法 | 说明 | 权限 |
|------|------|------|------|
| /api/v1/academic/bind | POST | 绑定教务账号 | 登录用户 |
| /api/v1/academic/status | GET | 查询绑定状态 | 登录用户 |
| /api/v1/academic/unbind | DELETE | 解除绑定 | 登录用户 |

### 3.2 绑定请求参数

```json
{
  "student_id": "2021001001",
  "password": "教务密码"
}
```

### 3.3 绑定状态响应

```json
{
  "code": 0,
  "data": {
    "is_bound": true,
    "student_id": "2021001001",
    "real_name": "张三",
    "college": "计算机学院",
    "major": "软件工程",
    "grade": "2021",
    "bound_at": "2026-03-10T10:00:00Z"
  }
}
```

### 3.4 敏感信息脱敏规则

| 字段类型 | 脱敏规则 | 示例 |
|----------|----------|------|
| 手机号 | 保留前3后4 | 138****1234 |
| 微信号 | 保留前2后2 | ab****yz |
| QQ号 | 保留前2后2 | 12****89 |
| 真实姓名 | 保留姓，名用* | 张** |
| 地址 | 只显示区域 | 北京市海淀区**** |

### 3.5 权限控制点

| 操作 | 未绑定用户 | 已绑定用户 |
|------|------------|------------|
| 浏览列表 | ✅ 脱敏显示 | ✅ 完整显示 |
| 查看详情 | ✅ 脱敏显示 | ✅ 完整显示 |
| 发布任务 | ❌ 提示绑定 | ✅ 允许 |
| 接单/预约 | ❌ 提示绑定 | ✅ 允许 |
| 发布商品 | ❌ 提示绑定 | ✅ 允许 |
| 发布失物招领 | ❌ 提示绑定 | ✅ 允许 |

## 4. 非功能需求

### 4.1 安全性
- 教务密码不存储，仅用于一次性验证
- 绑定信息加密存储
- 解绑需要二次确认

### 4.2 性能
- 教务验证超时时间：10秒
- 绑定状态缓存：Redis 24小时

### 4.3 兼容性
- 支持多所高校教务系统（可扩展）
- 当前版本：模拟验证（开发阶段）

## 5. 数据模型

### 5.1 academic_bindings 表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| user_id | bigint | 用户ID，外键 |
| student_id | varchar(20) | 学号 |
| real_name | varchar(50) | 真实姓名 |
| college | varchar(100) | 学院 |
| major | varchar(100) | 专业 |
| grade | varchar(10) | 年级 |
| status | tinyint | 状态：1-正常 0-已解绑 |
| bound_at | datetime | 绑定时间 |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 更新时间 |

### 5.2 索引
- `idx_user_id`: 用户ID索引（唯一）
- `idx_student_id`: 学号索引

## 6. 错误码

| 错误码 | 说明 |
|--------|------|
| 40001 | 未绑定教务账号 |
| 40002 | 教务账号验证失败 |
| 40003 | 学号已被其他账号绑定 |
| 40004 | 绑定信息不存在 |

## 7. 开发阶段说明

由于无法直接对接真实教务系统，开发阶段采用**模拟验证**：
- 任意学号 + 密码 "123456" 视为验证成功
- 返回模拟的姓名、学院等信息
- 后续可替换为真实教务接口
